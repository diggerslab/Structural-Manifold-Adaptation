# SMA：结构流形驱动的模型快速适配

**Structural Manifold Adaptation for Rapid VLA Fine-Tuning**

[English](README.md) · [算法细节](docs/algorithm.md) · [接入说明](docs/integration.md)

SMA把有限的微调时间分配给更值得学习的示范片段。它使用结构邻接图、训练覆盖程度和当前残差决定采样优先级，保留原模型架构与原训练目标。本仓库将研究实现中的 **S2机制** 整理为独立的NumPy模块。

## 通俗理解

普通微调按既定分布抽取训练片段。SMA先按“看到了什么、机械臂处于什么状态、需要执行什么动作”组织片段，再调整训练时的抽取机会。

例如，同样面对抽屉，“伸手”“抓住把手”“拉动”可能需要不同动作。仅凭画面相似度容易混淆这些阶段，SMA同时考虑末端位姿、夹爪与专家动作，并限制不兼容阶段之间的图连接。

每个全局批次中，一半仍按任务、轨迹、时间窗分层均匀采样；另一半按照结构覆盖和归一化残差分配。它既不是只挑最大的loss，也不修改模型的动作监督目标。

## 运行

```bash
git clone https://github.com/diggerslab/Structural-Manifold-Adaptation.git
cd Structural-Manifold-Adaptation
python -m pip install -e .
python -m sma.demo --output demo-output
python -m unittest discover -s tests -v
```

仅需Python 3.10+和NumPy。示例使用合成数据，在CPU上完成图构建、采样更新及断点恢复检查，不需要下载模型，不代表机器人成功率实验。

## 保留的S2机制

1. **结构距离**：冻结初始模型的视觉语言特征、末端几何、夹爪描述、有效专家动作，共四个等权块。
2. **局部图**：任务内选取代表窗，只连接夹爪阶段兼容的近邻，构造扩散核。
3. **可达覆盖目标**：目标包含强制均匀采样的一半，避免优先分支追逐不可能达到的分布。
4. **动态分配**：区域基础份额 × 相对初始残差 × 覆盖修正，再限制任务份额。
5. **固定混合**：默认每64个样本中32个均匀、32个优先，随后打乱。

## 接入边界

仓库包含算法内核、输入规范、示例、测试与原代码数值对照；不包含模型权重、实验数据、仿真服务或完整π0.5训练环境。真实训练时需要提供冻结特征、原生训练函数和逐窗残差。多卡时全局只抽样一次，分发到各卡，再按原顺序汇总反馈。

当前参考状态为8维、动作为7维，详细字段见接入文档。扩展到其他本体时需要明确修改字段映射，不能直接把不同控制语义拼在一起。

“流形”在这里是结构先验构成的离散局部图，不等于恢复真实物理流形。SMA不添加表示一致性损失，也不增加推理模块。它旨在提升短预算数据利用效率，不宣称对所有模型普遍有效。
